# Local speech runtime

The Nemotron helper uses sherpa-onnx (Apache-2.0) and ONNX Runtime (MIT).
Required license texts are included in this directory.

- sherpa-onnx: https://github.com/k2-fsa/sherpa-onnx
- ONNX Runtime: https://github.com/microsoft/onnxruntime
- Nemotron model: https://huggingface.co/nvidia/nemotron-3.5-asr-streaming-0.6b
- Nemotron CPU export: https://github.com/k2-fsa/sherpa-onnx/releases/tag/asr-models

Speech model weights download separately to the user's application data directory.
Model weights retain their respective NVIDIA licenses.
